## 💜 Quem somos

A **POP** não é mais uma aplicação no mercado. Somos uma solução de mobilidade **desenhada por portugueses, para portugueses** e para quem reside em Portugal — com um compromisso claro: oferecer um serviço **justo, transparente e digno**, tanto para quem viaja como para quem conduz.

Acreditamos que o sucesso começa por **respeitar e apoiar os motoristas** que fazem a diferença no dia a dia. Por isso praticamos **comissões mais baixas**, para garantir que o esforço de cada motorista é **sempre recompensado de forma justa**.
